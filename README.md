## 🔥 Projetos em destaque

### 📚 DVA Focus: plataforma de estudo com IA para a AWS DVA-C02

Plataforma que criei e usei na preparação para a **AWS Certified Developer Associate**, em que fui aprovado. Funciona como um tutor que se adapta aos meus erros:

- Banco com **440+ questões**, repetição espaçada (SM-2) e modos no formato da prova: simulado cronometrado, blitz e múltipla resposta
- **Diagnóstico de comportamento:** separa erro técnico de erro estratégico (leitura apressada, pegadinha de palavra-chave)
- **IA integrada** (Gemini com fallback para Groq): gera questões novas, analisa o raciocínio em cada erro e um coach reordena o plano de estudo do dia
- **Stack:** Next.js 15, TypeScript, Tailwind, PostgreSQL (Neon), autenticação JWT e deploy na Vercel
